# Method: research-report

Investigate questions, evaluate options, and synthesize data into decisions.

## Steps

1. Frame question & falsifiability: state hypothesis, decision criteria, and what would refute it.
2. Gather primary evidence: measure, benchmark, or read primary sources directly; no hearsay.
3. Explain the numbers: identify limiting factors ("why not double?"), sample counts, and noise margins.
4. Synthesize tradeoffs: build structured comparison tables with concrete costs and tradeoffs.
5. Apply unslop: write in active voice, plain words, and sentence case; eliminate fluff and hype.

## Principles

- `explain-the-number`: Name the limiting resource and what bounds the number; rule out artifacts.
- `prove-it-works`: Base conclusions on reproducible data or direct observation, never assumptions.
- `minimize-reader-load`: Lead with the bottom line; structure tables for rapid executive scanning.

## Evidence

- Exact commands run, sample counts, and raw measurement output.
- Tradeoffs matrix comparing alternatives with cited sources.
- Saved report artifact in `artifacts/<task-id>/`.
