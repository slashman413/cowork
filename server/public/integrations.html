Add a repository

Shallow clone, no repo code is executed. Cowork detects what the repo is — agent skill(s) (SKILL.md), static web app (index.html), MCP server, CLI or library — and runs the static security audit. Skills are installed to the shared skills home and linked into every agent client; web apps become a sandboxed Portal card. CLIs / MCP servers / libraries can be wrapped as a skill by an engineering agent. CRITICAL audit findings quarantine the repo.
